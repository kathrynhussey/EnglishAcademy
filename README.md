# Kathryn English Courses website

A static, mobile-first multilingual website for GitHub Pages.

## Before publishing
1. Add Kathryn's portrait as `assets/kathryn-photo.jpg` (portrait orientation recommended, at least 1200 × 1500 px). The included placeholder appears until you do.
2. Replace the five sample testimonials in `script.js` with genuine, authorised feedback. Do not publish invented testimonials as real reviews.
3. Review prices, SIRET, legal wording, cancellation terms, privacy information and the Qualiopi/CPF statement.
4. Optional: connect a custom domain by adding it in GitHub Pages settings.

## Publish on GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `english-courses-kathryn`.
2. Extract the ZIP. Upload the contents of the folder, not the outer folder itself, so `index.html` is at the repository root.
3. Select **Add file > Upload files**, drag all files and the `assets` folder, then select **Commit changes**.
4. Open **Settings > Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main**, folder **/(root)**, then **Save**.
7. Wait about 1–5 minutes. GitHub will display the public address, usually `https://YOUR-USERNAME.github.io/english-courses-kathryn/`.

## Update later
Edit files directly on GitHub or upload replacements, then commit. GitHub Pages republishes automatically.

## Files
- `index.html`: page structure and content
- `styles.css`: colours, responsive layout and accessibility styles
- `script.js`: language switching, mobile navigation, testimonials and scroll effects
- `assets/adult-english-class.png`: generated hero visual
- `assets/kathryn-placeholder.svg`: temporary portrait placeholder
